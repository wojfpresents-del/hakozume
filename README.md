# ハコヅメ

中の見えない入れ物に、みんなで順番に物を詰めていくパーティーゲーム。**溢れさせた人の負け！**

▶ **遊ぶ：** https://wojfpresents-del.github.io/hakozume/

- 1〜4人（CPU戦／1台を回して遊ぶプレイヤー戦）
- サイズ（S/M/L/XL）を選ぶと、ドローンが物を運んでくる → 入れ物の上で離す
- 揺らす・覗くのスキル、ギブアップ、ぴったりボーナス
- 入れ物は18種類（重箱、ランドセル、ポスト、水槽、ノアの方舟、地球 ほか）

スマホの縦画面向けです。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（1ファイルで完結） |
| `build.py` | 開発用：ゲームの元ファイルから `index.html` を作る |
| `deploy.sh` | 開発用：ビルド → コミット → push を1回で行う |
